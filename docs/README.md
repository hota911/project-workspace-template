# 関係者と知識

プロジェクトをまたいで参照・更新する Stock 型の文書を置く。

- 関係者は `people.md` に役割、関わるプロジェクト、根拠と確認日を記録する。文書が増えた場合は `people/` 内で分ける。
- 知識は `knowledge/<テーマ>.md` に記録する。必要になったときにディレクトリを作る。
- プロジェクト固有の文書は `projects/<name>/` に置く。
- 日付を追う作業の経緯は `logs/` に残し、ここには現在参照すべき内容と根拠へのリンクを記録する。

人物評価など外部共有できない情報は [情報管理のルール](../AGENTS.md) に従い、`local/` に置く。
