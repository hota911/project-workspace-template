# 稼働時間

稼働時間のマスターデータを月別の `YYYY-MM.csv` に記録する。
当月のファイルがなければ [_template.csv](_template.csv) をコピーする。たとえば 2026 年 9 月の記録先は `2026-09.csv` である。
作業の経緯や補足は日別ログに記録する。稼働時間は CSV にのみ記録する。

## 列と記入方法

| 列 | 形式 |
| --- | --- |
| 日付 | `YYYY-MM-DD`。ファイル名と同じ月の日付である。 |
| プロジェクト | 同じプロジェクトは同じ名前で記録する。プロジェクトに属さない作業は `単発` とする。 |
| 作業内容 | 作業を識別できる短い説明である。 |
| 開始 | 日本時間の `HH:MM`。不明な場合は空欄である。 |
| 終了 | 日本時間の `HH:MM`。日末は `24:00` とする。不明な場合は空欄である。 |
| 休憩分 | 0 以上の整数である。休憩なしは `0`、不明な場合は空欄である。 |
| 稼働分 | 確認済みの稼働時間を分単位の整数で記録する。不明な場合は空欄である。 |

開始時に行を追加し、終了時に同じ行を更新する。再開した作業は別の行に記録する。
日をまたぐ作業は日付ごとに分け、翌日分は `00:00` から記録する。月をまたぐ場合は各月のファイルへ分ける。
開始・終了・休憩が確認できれば、稼働分は終了と開始の差から休憩分を差し引いて記入する。
本人が稼働時間だけ申告した場合は、時刻や休憩を推測せず稼働分だけ記入する。
並行作業や休憩の扱いに確認が必要な場合は、日別ログに補足を記録し、未確定の稼働分は空欄にする。

CSV は UTF-8、カンマ区切り、先頭行を列名とする。列の順序を揃え、月ごとのファイルに同じ列名を付ける。
カンマやダブルクォートを含む値はダブルクォートで囲み、値の中のダブルクォートは2つ重ねる。作業内容は改行せず1行で記録する。
数値欄には単位や `未確認` などの文字を入れない。合計行や説明文は CSV に追加しない。

## 記入例

以下は架空の例である。雛形には実績を入れず、列名だけを置く。

```csv
日付,プロジェクト,作業内容,開始,終了,休憩分,稼働分
2026-09-17,個人サイト,記事の執筆,09:00,10:30,10,80
2026-09-17,個人サイト,構成の検討,,,,45
2026-09-17,単発,資料の整理,14:00,,,
```

## 集計

`YYYY-MM.csv` の稼働分を月別・プロジェクト別に合計する。雛形は集計対象に含めない。
稼働分が空欄の行は 0 分として扱わず、未確認の件数を集計結果に添える。
時間単位で表示する場合は、合計した稼働分を 60 で割る。
請求情報が必要な場合は [開始時チェックリスト](../../onboarding.md) で運用を決める。
